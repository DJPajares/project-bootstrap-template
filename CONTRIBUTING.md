# Contributing

Contributions are welcome.

## What To Improve

Useful contributions include:

- clearer generation rules
- better frontend/backend/full-stack examples
- better task templates
- better model/reasoning guidance
- reduced duplication
- improved README examples

## Guidelines

- Keep `PROJECT_BOOTSTRAP.md` practical and reusable.
- Keep generated `AGENTS.md` guidance brief and token-efficient.
- Avoid adding project-specific assumptions that do not generalize.
- Prefer concise examples over long explanations.

## Suggested Commit Format

Use Conventional Commits when possible:

```text
type(scope): summary
```

Examples:

```text
docs(readme): clarify project mode selection
docs(bootstrap): add frontend task guidance
chore(repo): add public repository metadata
```
